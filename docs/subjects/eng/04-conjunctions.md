# Conjunctions

## Core rules and method
**Coordinating:** for, and, nor, but, or, yet, so (FANBOYS). Example: I was tired, but I completed the task.

**Subordinating:** because, although, if, when, while, since, unless, before, after. Example: Although it was raining, we went out.

**Correlative:** either…or, neither…nor, both…and, not only…but also. Example: Both Rina and Mina are present.

**Purpose/result:** so that, so…that, such…that.

## Examples / Practice with answers
1. I stayed home ___ I was ill. — because
2. ___ he is poor, he is honest. — Although
3. Work hard ___ you may succeed. — so that
4. You cannot enter ___ you have a ticket. — unless
5. ___ Rafi or Sami will lead the team. — Either
6. She is not only intelligent ___ hardworking. — but also

## Exam tips
**Avoid:** Although…but in the same simple clause ✗; use Although it was late, we continued. / It was late, but we continued.

**Punctuation:** When a dependent clause comes first, a comma commonly separates it from the main clause.
