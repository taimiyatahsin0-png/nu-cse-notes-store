
# Structured Programming Language Lab

**Course Code:** 510202  
**Marks:** 40  
**Credits:** 1.5  
**Related Theory Course:** 510201 – Structured Programming Language

## Course Objectives

This laboratory course is based on Structured Programming Language (510201).

The main objectives are to develop practical skills in:

- Designing C programs
- Developing and implementing programs
- Debugging programs
- Testing programs
- Maintaining programs
- Solving problems using C programming

## Laboratory Activities

Students will regularly solve programming problems to improve their practical programming skills.

### Programming Practice

- Practice based on the topics covered in SPL Theory
- Writing and executing C programs
- Identifying and correcting programming errors
- Testing and debugging programs
- Developing problem-solving skills

## Practical Notes

- [Standard C Programming Lab Report Format](lab-report-format.md) — suggested template for writing practical reports.

- [Practical 01: Basic Structure of a C Program](01-basic-structure-of-c-program.md) — suggested foundational practical; verify experiment order with your department's current lab manual.
- [Practical 02: Basic Input and Output Operations](02-basic-input-output-and-addition.md) — suggested exercise on variables, `scanf()`, `printf()`, and arithmetic.
- [Practical 03: Arithmetic Operations in C](03-arithmetic-operations.md) — suggested practice on arithmetic operators and division-by-zero handling.
- [Practical 04: Relational and Logical Operators in C](04-relational-and-logical-operators.md) — suggested practice on comparisons and combined conditions.
- [Practical 05: Decision Making Using if, if-else, and Nested if](05-decision-making-if-else.md) — suggested practice on conditional statements.
- [Practical 06: Switch Statement and Menu-Driven Program](06-switch-statement-menu-driven.md) — suggested practice on `switch`, `case`, `break`, and `default`.
- [Practical 07: Looping Statements in C (for, while, and do-while)](07-looping-statements-for-while-do-while.md) — suggested practice on the three basic loop structures.
- [Practical 08: Nested Loops and Pattern Printing in C](08-nested-loops-pattern-printing.md) — suggested practice on nested loops, star patterns, number patterns, and multiplication tables.
- [Practical 09: Arrays and Strings in C](09-arrays-and-strings.md) — suggested practice on one-dimensional arrays, matrices, and basic string operations.
- [Practical 10: Functions in C](10-functions-in-c.md) — suggested practice on function prototypes, definitions, calls, arguments, return values, and pass by value.
- [Practical 11: Structure and Union in C](11-structure-and-union.md) — suggested practice on structure variables, arrays of structures, function parameters, unions, and memory sharing.
- [Practical 12: Pointers in C](12-pointers-in-c.md) — suggested practice on pointer declaration, addresses, dereferencing, arrays, and function arguments.
- [Practical 13: File Management in C](13-file-management-in-c.md) — suggested practice on creating, writing, reading, and appending text files.
- [Practical 14: Header Files, Preprocessor and Library Functions](14-header-files-preprocessor-library-functions.md) — suggested practice on header inclusion, macros, and standard library functions.
- [Practical 15: Error Handling in C](15-error-handling-in-c.md) — suggested practice on input validation, runtime checks, file errors, and debugging.
