
# Structured Programming Language (SPL)

**Course Code:** 510201  
**Marks:** 80  
**Credits:** 3.0  
**Class Hours:** 45

This course introduces the fundamentals of structured programming using the C programming language.

## Official Syllabus Topics

### 1. Programming Fundamentals
- Overview of Structured Programming Language
- Algorithm
- Flowchart
- Pseudocode

### 2. Constants, Variables and Data Types
- Constants
- Variables
- Data Types

### 3. Operators and Input/Output
- Operators and Expressions
- Managing Input Operations
- Managing Output Operations

### 4. Decision Making and Looping
- Decision Making and Branching
- Looping

### 5. Arrays and Strings
- Arrays
- Handling of Character Strings

### 6. Functions
- User-defined Functions
- Parameter Passing Conventions
- Scope Rules
- Storage Classes
- Recursion

### 7. Advanced Programming Concepts
- Structure and Union
- Pointers
- File Management
- Header Files
- Preprocessor
- Library Functions
- Error Handling
