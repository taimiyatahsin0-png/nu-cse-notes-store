## How to solve a programming problem

1. **Understand the problem:** identify inputs, outputs and constraints.
2. **Write the logic:** describe the steps in plain language.
3. **Dry run:** test the logic with small sample values.
4. **Write C code:** use clear variable names and correct types.
5. **Compile and test:** test normal values and boundary cases.
6. **Explain the output:** be able to trace each important variable.

## Good practice rules

- Compile frequently; do not write a very long program before testing.
- Read compiler errors carefully and fix the first meaningful error first.
- Avoid unsafe input functions such as `gets()`.
- Initialize variables before using them.
- Test boundary values, empty input and invalid input where relevant.
- Never copy code without understanding its logic.
