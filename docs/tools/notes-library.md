## How to use the library

- Use the subject filter to focus on one course.
- Use the resource-type filter to find chapter notes, revision guides or laboratory materials.
- Use the global search shortcut **Ctrl + K** to search the full text of the website.
- Bookmark a page to keep it in your personal reading list on this device.

The library index is updated as new resources are published. Course and syllabus information should be checked against the latest version confirmed by your department.
